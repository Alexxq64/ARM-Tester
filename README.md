Краткая инструкция пользователя АРМ
1. Запуск
Запустить файл gui/main_window.py в среде Linux (целевая платформа).

2. Управление проектами
Создать проект: нажать «Добавить проект» → ввести название и описание → OK.

Загрузить список проектов: нажать «Загрузить проекты». При первом запуске создаётся тестовый проект.

Открыть тесты проекта: дважды кликнуть по строке проекта.

3. Управление тестами
Добавить тест: нажать «Добавить тест» → ввести название, группу, выбрать файл с тестами pytest (.py) через «Обзор» → OK.

Важно: АРМ работает только с pytest. Файл должен содержать функции test_* и проверки через assert.

Редактировать тест: выделить строку → «Редактировать» (или дважды кликнуть) → изменить → OK.

Удалить тест: выделить → «Удалить» → подтвердить.

Фильтрация: поиск по названию, выбор группы, фильтр по активности.

Сортировка: клик по заголовку таблицы.

4. Запуск тестов
Запустить выбранные: выделить тесты → «Запустить выбранные».

Запустить все активные: «Запустить все активные».

После завершения откроется окно с детальными результатами.

5. История запусков
Нажать «История запусков».

Фильтр по дате: выбрать диапазон → «Применить фильтр».

Показать результаты: выбрать запуск → «Показать результаты» (или дважды кликнуть).

Удалить запуск: выбрать один или несколько → «Удалить выбранные» → подтвердить.

6. Аналитика
В окне истории запусков нажать «Аналитика (график)» → откроется график динамики тестов.

7. Отчёты
Сохранить отчёт: в окне детальных результатов нажать «Сохранить отчёт» → выбрать место → OK.

Просмотр отчёта: в окне истории запусков выбрать запуск → «Отчёты» → выбрать строку → «Открыть папку» → дважды кликнуть по HTML-файлу.

8. Закрытие
Закрыть окно приложения. База данных сохраняется автоматически.
